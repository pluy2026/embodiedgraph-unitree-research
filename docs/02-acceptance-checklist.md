# 交付验收清单

本清单用于把测试题要求转换为可执行、可检查的交付标准。开发过程中逐项勾选，提交前全部复核。

## A. 研究对象与关系覆盖

- [x] 研究对象确定为宇树科技。
- [x] README 说明选择理由、研究范围与时间截点。
- [ ] 数据结构支持 `supplier`。
- [ ] 数据结构支持 `customer`。
- [ ] 数据结构支持 `partner`。
- [ ] 数据结构支持 `investor_or_investee`。
- [ ] 数据结构支持 `peer`。
- [ ] 每条关系包含方向、关系类型和实体身份。
- [ ] 每条关系包含事实、推断或未知状态。
- [ ] 每条关系包含时效信息和不确定性说明。

## B. 来源与证据

- [ ] 仅使用无需登录、无需付费、无需绕过限制的公开资料。
- [ ] 每条关系保留 source URL。
- [ ] 每条关系保留 publisher。
- [ ] 每条关系保留发布日期或时间范围。
- [ ] 每条关系保留获取时间。
- [ ] 每条关系保留 evidence locator。
- [ ] 每条关系记录访问或许可限制。
- [ ] 来源冲突被保留，不被静默覆盖。
- [ ] 转载来源能够追溯到共同的原始出处。

## C. 置信度与解释

- [ ] 每条关系提供 0-100 置信度。
- [ ] 评分考虑来源权威性。
- [ ] 评分考虑证据直接性。
- [ ] 评分考虑多源独立性。
- [ ] 评分考虑时效性。
- [ ] 评分考虑关系描述的具体程度。
- [ ] 页面解释分数如何形成。
- [ ] 明确说明置信度不代表关系的重要程度。

## D. 代码与运行

- [ ] 代码托管于公开 GitHub 仓库。
- [ ] 仓库不依赖 reviewer 重新抓取受限数据才能运行。
- [ ] 提供固定 fixture 或 snapshot。
- [ ] 提供 HTTP JSON API。
- [ ] 提供命令行查询入口。
- [ ] 支持公司关系查询。
- [ ] 支持关系图谱或邻接查询。
- [ ] 支持证据查询。
- [ ] 支持有输入校验的筛选与分页。
- [ ] 支持关系类型、状态、时间或置信度筛选。

## E. README 与复现

- [ ] README 包含环境要求。
- [ ] README 包含安装步骤。
- [ ] README 包含启动命令。
- [ ] README 包含测试命令。
- [ ] README 包含数据更新流程。
- [ ] README 包含复现步骤。
- [ ] README 包含样例请求和响应。
- [ ] README 说明研究限制和已知盲区。

## F. 测试与失败边界

- [ ] 覆盖至少一条完整关键路径测试。
- [ ] 覆盖非法关系类型。
- [ ] 覆盖非法分页和置信度范围。
- [ ] 覆盖实体或关系不存在。
- [ ] 覆盖证据缺失或来源不可用。
- [ ] 覆盖过期证据提示。
- [ ] 覆盖来源冲突状态。
- [ ] 测试无需外部网络即可运行。

## G. AI 与人工责任

- [ ] README 说明使用了哪些 AI 或 Agent 工具。
- [ ] 说明 AI 用于检索、摘要、结构化或代码辅助的具体环节。
- [ ] 说明人工核验步骤。
- [ ] 不向工具输入个人数据、客户机密或未授权材料。
- [ ] 最终研究判断由提交者本人负责。
- [ ] 保留典型的 AI 建议被人工否决或修正的示例。

## H. 产品体验

- [ ] 首页能快速理解项目价值和研究范围。
- [ ] 关系图能够区分方向、类型和状态。
- [ ] 证据详情能够返回原始来源。
- [ ] 推断关系具有明显视觉提示。
- [ ] 未知关系不会被显示为已确认关系。
- [ ] 过期和冲突证据具有明显提示。
- [ ] 方法说明能够让 reviewer 理解评分与判断逻辑。
