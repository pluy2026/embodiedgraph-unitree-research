# 关联上市公司口径审计

审计日期：2026-09-01  
适用快照：`unitree-mvp-2026-08-29`

## 结论

宇树官网披露的 B2 融资名单可以确认历史融资/跟投事实，但名单中的投资机构**不能因为被披露为投资方，就自动被视为上市公司主体**。本项目将“历史资本结构事实”和“关联上市公司覆盖”拆开统计。

| 快照实体 | 结论 | 是否计入关联上市公司覆盖 | 依据与呈现方式 |
|---|---|---:|---|
| 美团 | 上市公司/集团关联主体 | 是 | 保留为美团（3690.HK）关联的历史融资记录。宇树招股材料明确披露汉海信息、成都龙珠、Galaxy Z 与美团的关联关系。 |
| 中信金石（原“金石投资”） | 中信证券关联投资主体 | 是（仅关联口径） | 中信金石是中信证券全资设立的私募基金子公司；页面不将其写成中信证券直接出资。 |
| 源码资本 | 投资机构 | 否 | 保留历史融资事实；不作为上市公司主体。 |
| 深创投 | 国有创投集团 | 否 | 国资背景不等于上市公司主体；保留历史融资事实。 |
| 容亿投资 | 基金/管理人 | 否 | 目前未保留可复核的上市主体控制链。 |
| 敦鸿资产 | 资产管理/投资机构 | 否 | 目前未保留可复核的上市主体控制链。 |
| 中国互联网投资基金 | 基金主体 | 否 | 目前未保留可复核的上市主体控制链。 |

## 产品规则

1. `relationships` 的 `scope_class` 仅在融资关系中使用：
   - `listed_issuer_or_group`：可计入；
   - `listed_group_affiliate`：可计入关联口径，但必须标明法定出资主体；
   - `nonlisted_capital_record`：保留为资本结构事实，不计入关联上市公司覆盖。
2. 34 条是公开可追溯的**关系记录总数**，不是“34 条上市公司关系”的宣称。
3. 后续新增腾讯、阿里巴巴、中国移动等关系时，必须同时保留两层证据：宇树融资文件中的法定投资主体，以及该主体与上市公司的控制/关联链。只有两层同时成立，才可标为 `listed_issuer_or_group` 或 `listed_group_affiliate`。
